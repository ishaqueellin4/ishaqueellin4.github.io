# Ishaque Ellin — Light Glass Portfolio

A responsive, single-file portfolio redesign using HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Download and extract the ZIP.
2. Open the GitHub repository connected to `ishaqueellin4.github.io`.
3. Replace the existing `index.html` with this file (keep a backup first).
4. Commit the changes.
5. Open https://ishaqueellin4.github.io/ and refresh after GitHub Pages deploys.

## Before publishing
- Add your real email/contact address if you want email contact.
- Replace Facebook, Instagram and YouTube placeholder links with your verified profile URLs.
- Skill bars are visual design elements, not measured proficiency scores; adjust them to match your real skill level.
