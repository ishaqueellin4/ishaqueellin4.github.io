# Ishaque Ellin — Light Glass Portfolio

Responsive single-file portfolio with a white/light-cyan glassmorphism design, animated welcome screen, English default language with a Bangla toggle, profile photo, and Facebook/Instagram/WhatsApp links.

## Publish on GitHub Pages
1. Extract the ZIP.
2. Open the repository connected to `ishaqueellin4.github.io`.
3. Replace the existing `index.html` with this `index.html` (keep a backup first).
4. Commit the change and wait for GitHub Pages to deploy.
5. Visit `https://ishaqueellin4.github.io/` and refresh.

The profile image is loaded from `https://raw.githubusercontent.com/ishaqueellin4/ishaqueellin4.github.io/main/profile.jpg`. Keep `profile.jpg` in the repository root.
